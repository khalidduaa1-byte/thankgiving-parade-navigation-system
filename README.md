# Navigating New York City during the 100th annual Macy’s Thanksgiving Day Parade

## Workshop prompt

Build a city navigation agent that helps New Yorkers get where they need to go during the parade. The agent should monitor disruptions, understand each traveler’s plans and preferences, and adapt their journey in real time with minimal effort from the traveler.

Work in pairs. You have **25 minutes** to develop a solution and submit your first version through the link shared by the organizers. You may use the Google Maps Platform API or another mapping API.

## Apply the workshop framework

| Question | How it applies to parade navigation |
| --- | --- |
| Customer journey | When does a traveler first need help, and what happens if their route changes after they leave? |
| Distribution | What would lead an AI assistant to call your navigation service when a traveler asks for help? |
| Value | What does your service contribute beyond the traveler’s existing map app? How does providing that help create value for the service? |
| Control and safeguards | Which changes can the agent make on its own, and which should the traveler approve? |
